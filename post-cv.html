A CV verified by code, not eyeballs

Nov 2026 · 2 min read · Craft

Contents

    The problem with looking

    My revamped CV looked perfect — until page two, where the skills and referees sat half outside the frame. Eyeballs miss this; geometry doesn't. So the rebuild pipeline ends with a checker, not a glance.

    The checker

    A small Node script reads the PDF's text items and asserts each one sits inside the printed border, with key strings present on the right pages:

    const ok = x0 >= BX0 - TOL && x1 <= BX1 + TOL
        && y0 >= BY0 - TOL && y1 <= BY1 + TOL;
if (!ok) fail(`OUT-OF-FRAME: ${str}`);

    Same idea as testing software: the artifact proves itself on every build.

    Steal this habit

    Anything you deliver repeatedly deserves a machine check — resumes, reports, invoices. Write the assertion once; never ship a silent regression again.
